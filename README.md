# QuickStart-on-SteamOS

>[!NOTE]
>I did not make this solution, I only added the steps to make it easier for other people to install the Quick Start mod for Sea Power. </br>
>Here's the link for the initial guide if you want to use that instead. [Click Here](https://docs.bepinex.dev/articles/advanced/proton_wine.html) </br>
>Also make sure that you've installed the Anchor Chain mod as it depends on that. [Youtube Guide](https://youtu.be/qc88egsV-2g) </br>
>Someone much smarter than me made this initial guide, I've got no clue how it works. If you need help I'll do my best to assist you. </br>

## 1. Use Discover to download protontricks
<img width="940" height="726" alt="Screenshot_20260820_225120" src="https://github.com/user-attachments/assets/41f29ed5-7250-4f63-8331-6d2b76092bb6" /> <br/>

## 2. Open ProtonTricks and select Sea Power
<img width="597" height="429" alt="Screenshot_20260820_225304" src="https://github.com/user-attachments/assets/ca22e5f7-cae1-4bf5-ac98-29924980b7ce" /> <br/>

> [!IMPORTANT]
> If you have Sea Power on a different disk than your main drive, you will have to run the command it asks you with sudo. If this doesn't apply to you, skip it.
Because sudo required a password, you'll need to set one in Konsole with the "passwd" command.
<img width="909" height="492" alt="Screenshot_20260820_230135" src="https://github.com/user-attachments/assets/041043f2-0440-4b9b-afd6-e5526fec536e" /> <br/>

## 3. Select the default wine prefix.
<img width="1006" height="520" alt="Screenshot_20260821_174205" src="https://github.com/user-attachments/assets/3449c3bc-d79f-4c98-aae0-ffb45bf28b1b" /> <br/>

## 4. Select 'Run winecfg'
<img width="1006" height="520" alt="Screenshot_20260821_174136" src="https://github.com/user-attachments/assets/d044bdb3-6394-4d77-8198-4590da44a141" /> <br/>

## 5. Select Libraries and add 'winhttp'
After that, click apply and close it out. </br>
<img width="408" height="214" alt="Screenshot_20260821_174455" src="https://github.com/user-attachments/assets/290d610d-a47e-4dbd-8616-b21d5341a8a6"/> </br>

## 6. Close out ProtonTricks and enable quickstart in SeaPower.
Everything should work after that, but make sure to fully restart the game after enabling the mods.
